# system-browser-open-discipline — reference

## Optional environment appendix

These notes improve how Markdown looks **after** a system-browser open. They are **not** prerequisites and MUST NOT block an open.

### Markdown rendering in the browser

Some browsers need an extension to render local `.md` files as formatted Markdown. If rendering looks like raw text, the human can install a Markdown viewer extension for their system default browser. The agent may mention this once as a tip; it does not install extensions as part of this skill's success path.

### File associations

If double-clicking `.md` / `.html` outside the agent does not open the system default browser, the human can set the OS default application for those types to their browser. Agent-initiated opens that use the OS default handler follow whatever association is already configured.
