# tech-research-workflow Specification

## REMOVED Requirements

### Requirement: The skill SHALL run research in a three-step order before any design conclusion

**Reason**: The skill id is hard-cut to `competitive-research`.
**Migration**: Use the same requirement on `competitive-research`.

### Requirement: Self business audit SHALL produce an asset/hazard inventory with code-level evidence

**Reason**: The skill id is hard-cut to `competitive-research`.
**Migration**: Use the same requirement on `competitive-research`.

### Requirement: Competitor research SHALL privilege first-hand runtime evidence over second-hand narratives

**Reason**: Competitor research now selects layers and records user-visible behavior before mechanism. The old id is hard-cut.
**Migration**: Use `competitive-research` requirements for layer selection, evidence-source grades, and the mechanism layer.

### Requirement: Design mapping SHALL classify every borrowed competitor element into exactly one of three tiers with rationale

**Reason**: The skill id is hard-cut to `competitive-research`.
**Migration**: Use the same requirement on `competitive-research`.

### Requirement: The first report version SHALL be treated as a constraint probe with an expected pushback

**Reason**: The skill id is hard-cut to `competitive-research`.
**Migration**: Use the same requirement on `competitive-research`.

### Requirement: Evidence standards SHALL bind every claim to reproducible evidence

**Reason**: Evidence standards now also require a source grade for competitor behavior claims. The old id is hard-cut.
**Migration**: Use the evidence-standards requirement on `competitive-research`.

### Requirement: A lean tailoring path SHALL exist for single-question research

**Reason**: The lean path is now the layer-selected path that problem-solving hosts load. The old id is hard-cut.
**Migration**: Use the lean layer-selected path requirement on `competitive-research`.

### Requirement: The report family SHALL be layered with distinct layers carrying distinct depth

**Reason**: The skill id is hard-cut to `competitive-research`.
**Migration**: Use the same requirement on `competitive-research`.

### Requirement: The skill SHALL abort when its declared dependency is missing

**Reason**: The skill id is hard-cut to `competitive-research`.
**Migration**: Use the `effective-web-research` dependency requirement on `competitive-research`.
